네이버 플레이스 노출 키워드 추출기

1. start-app.cmd를 실행합니다.
2. 처음 사용할 때는 "Chrome 로그인 열기"로 네이버 로그인을 완료합니다.
3. URL, 연도, 추출할 월을 선택합니다.
4. "노출 키워드 추출"을 누릅니다.
5. 앱은 아래 4개 광고 그룹만 탐색합니다.
   - 니즈키워드
   - 지역+마음수련
   - 지역+명상
   - 지역+상담
6. 결과는 노출수 높은 순에서 낮은 순으로 표시됩니다.
7. 노출수가 같으면 키워드를 한 칸에 콤마로 나열합니다.
8. 복사 버튼을 누르면 엑셀에 바로 붙여넣을 수 있는 2열 표가 복사됩니다.

결과 열:
- 노출수
- 키워드
